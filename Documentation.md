# The Universal Car Installer
## *What is this?*
-> The most simplest way to install/replace cars in Midnight Club 3 Dub Edition

## *How does it work?*
-> Place all your files inside the "Mod_module" folder.

-> Place your ASSETS.DAT file inside the "Workspace" folder.

-> Run install.py (Double Click on it)

-> It will show you all the files that will be replaced.

-> Type in the command "Y" to start the process, or "N" to safely exit.

-> It creates for you an automatic backup of your original file, in case there was a error/mistake during the process.

-> After it's done, you will have 2 files being your modified ASSETS.DAT and the backup being ASSETS.DAT.backup.

**Notes**: You do not need to rearrange anything, because it's auto detects everything, and will replace everything on it correct place, so don't worry about that.
It **automatically** detects flash pcks, the main .dat, garage model pcks, and even the .carcfg files if you have them.
